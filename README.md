# TracePilot

AI-native incident investigation + deterministic counterfactual replay for distributed backends.

> **Status: Phase 5 (server + web UI); Gate 3 still not verified.** The simulator, the
> `pool-exhaustion` scenario, the telemetry store, the analysis library, the investigation
> engine (`tracepilot investigate`), counterfactual replay (`tracepilot replay`, `sweep`) and the
> web UI (`tracepilot serve`) exist. On scenario A the analyzers find the root-cause signals
> without any LLM (Gate 2), and replaying the recommended patches resolves the simulated incident
> (Gate 4). The investigation engine is tested with a scripted stand-in for the model; **it has
> not yet been run against a real model**, which is what Gate 3 requires (see NOTES.md, Phase 3,
> for how to record that run).
> See [TRACEPILOT_BUILD_BRIEF.md](TRACEPILOT_BUILD_BRIEF.md) for the plan and [NOTES.md](NOTES.md)
> for the decision log.

## The three rules

1. **Numbers never come from the LLM.** Every number shown comes from a deterministic tool or the
   simulator.
2. **No claim without evidence.** Every diagnosis statement is a typed `FACT`, `INFERENCE` or
   `HYPOTHESIS`, and a deterministic verifier rejects anything whose cited evidence does not exist
   or does not match.
3. **No hardcoded demo.** Investigations run for real against the telemetry store. Recorded LLM
   runs are real past runs and are labeled as recorded.

## Honest framing

The demo telemetry is **synthetic**, generated by our own simulator. The investigator reaches
telemetry only through query tools. Lint rules stop the agent layer from importing simulator
internals or eval ground truth. Replays are a **model of system behavior, not a guarantee** of
production behavior.

## Development

Requires Node ≥ 22.12. pnpm is pinned via `packageManager`, so it runs through corepack:

```bash
corepack pnpm install
```

```bash
corepack pnpm run ci
```

`ci` runs format check, lint, typecheck and tests. Individual steps: `lint`, `typecheck`, `test`,
`format`.

Simulate scenario A. Its telemetry goes into `.data/telemetry.db` under a neutral incident ID;
the replay recording goes to `.data/sim/`, which only the simulator side reads:

```bash
corepack pnpm run tracepilot sim run --scenario pool-exhaustion --seed 42 --out .data
```

Print what the scenario produces (baseline, incident, counterfactuals, pool sweep):

```bash
corepack pnpm run calibrate
```

Investigate an incident (`sim run` prints its ID). This calls the Anthropic API with the
credentials in your environment (`ANTHROPIC_API_KEY`):

```bash
corepack pnpm run tracepilot investigate --incident in_rm6f1z3tf --out .data --stream
```

The diagnosis is printed with the ledger entries it cites, and the full record is saved to
`.data/investigations/`. `TRACEPILOT_LLM=record` also saves the model's responses to a cassette;
`TRACEPILOT_LLM=replay` re-runs the investigation from that cassette without the API and labels
the result as a recorded run. Other settings are listed in [.env.example](.env.example).

Replay the incident with a change, through the same simulator and the same recorded workload.
Every number in the comparison is simulator output, and every result says it is simulated from a
model of the system, not a guarantee of production behavior:

```bash
corepack pnpm run tracepilot replay --incident in_rm6f1z3tf --out .data --patch db.pool.capacity=64
```

```bash
corepack pnpm run tracepilot replay --incident in_rm6f1z3tf --out .data --revert ev_2
```

Replay every recommendation of a saved diagnosis, and see which treat the cause and which the
symptom:

```bash
corepack pnpm run tracepilot replay --incident in_rm6f1z3tf --out .data --diagnosis .data/investigations/in_rm6f1z3tf.json
```

Sweep one knob over a range to find the knee and where the bottleneck moves:

```bash
corepack pnpm run tracepilot sweep --incident in_rm6f1z3tf --out .data --param db.pool.capacity --range 20:120:10
```

Open the web UI (overview, incident timeline, investigation with clickable evidence, replay lab).
It needs no API key: it reads the saved investigation and replay records, and replays run in the
simulator. With no saved investigation, its Investigation view can run the scripted fixture
(labelled as such) or an investigation with the server's LLM settings.

```bash
corepack pnpm run web:build
```

```bash
corepack pnpm run tracepilot serve --out .data
```

Then open http://127.0.0.1:4318.

The native SQLite driver (`better-sqlite3`) may compile during install; that needs a C++
toolchain where no prebuilt binary exists.
