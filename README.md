# TracePilot

AI-native incident investigation + deterministic counterfactual replay for distributed backends.

> **Status: Phase 1 (simulator + scenario A).** The schema package, the deterministic simulator,
> the `pool-exhaustion` scenario and `tracepilot sim run` exist. The store, analysis, investigation
> and replay product features do not yet. See [TRACEPILOT_BUILD_BRIEF.md](TRACEPILOT_BUILD_BRIEF.md)
> for the plan and [NOTES.md](NOTES.md) for the decision log.

## The three rules

1. **Numbers never come from the LLM.** Every number shown comes from a deterministic tool or the
   simulator.
2. **No claim without evidence.** Every diagnosis statement is a typed `FACT`, `INFERENCE` or
   `HYPOTHESIS`, and a deterministic verifier rejects anything whose cited evidence does not exist
   or does not match.
3. **No hardcoded demo.** Investigations run for real against the telemetry store. Recorded LLM
   runs are real past runs and are labeled as recorded.

## Honest framing

The demo telemetry is **synthetic**, generated by our own simulator. The investigator reaches
telemetry only through query tools. Lint rules stop the agent layer from importing simulator
internals or eval ground truth. Replays are a **model of system behavior, not a guarantee** of
production behavior.

## Development

Requires Node ≥ 22.12. pnpm is pinned via `packageManager`, so it runs through corepack:

```bash
corepack pnpm install
```

```bash
corepack pnpm run ci
```

`ci` runs format check, lint, typecheck and tests. Individual steps: `lint`, `typecheck`, `test`,
`format`.

Generate scenario A (telemetry, a replayable recording and a manifest land in `.data/`):

```bash
corepack pnpm run tracepilot sim run --scenario pool-exhaustion --seed 42 --out .data
```

Print what the scenario produces (baseline, incident, counterfactuals, pool sweep):

```bash
corepack pnpm run calibrate
```
